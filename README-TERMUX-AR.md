# body bot — تشغيل على Termux

## تنبيه مهم
- هذا بوت غير رسمي يعتمد على Baileys؛ قد يتوقف بسبب تغييرات واتساب، واستخدام أدوات غير رسمية قد يعرّض الحساب للتقييد.
- اربطه بحساب مخصص إن أمكن، ولا ترسل ملفات مجلد `session` أو QR أو كود الاقتران لأي شخص.
- لا تستخدمه للإزعاج أو الرسائل الجماعية غير المرغوبة. جرّب أوامر الإدارة في مجموعة تملكها أو تديرها.
- تم حذف بيانات الجلسة الموجودة في الملف الأصلي. ستربط حسابك بنفسك عند أول تشغيل.

## 1) تثبيت Termux
ثبّت Termux من مصدره الرسمي F-Droid أو صفحة Termux على GitHub، ثم افتحه واكتب:

```bash
pkg update && pkg upgrade -y
pkg install nodejs-lts git python make clang ffmpeg -y
```

## 2) فك ضغط المشروع
انقل `body-bot-termux.zip` إلى مجلد التنزيلات في الهاتف، ثم داخل Termux:

```bash
termux-setup-storage
cd ~/storage/downloads
unzip body-bot-termux.zip
cd body-bot-termux
```
إذا فككت الملف في مكان آخر، انتقل إلى مجلد `body-bot-termux` الصحيح.

## 3) ضبط رقم المالك
افتح الإعدادات:

```bash
nano settings.js
```
عدّل `ownerNumber` واكتب رقم واتسابك بصيغة دولية بدون علامة `+` أو مسافات، مثل `2010XXXXXXXX`، ثم احفظ بـ `Ctrl+O` ثم Enter، واخرج بـ `Ctrl+X`.

## 4) تثبيت المكتبات

```bash
npm install --legacy-peer-deps
```
قد يستغرق ذلك وقتًا، ويحتاج اتصال إنترنت ومساحة كافية.

## 5) تشغيل البوت

```bash
npm start
```
سيظهر QR في شاشة Termux. في واتساب على الهاتف: **الأجهزة المرتبطة > ربط جهاز** ثم امسح QR الظاهر في Termux. إذا لم يظهر QR أو فشل الاتصال، أوقفه بـ `Ctrl+C` ثم جرّب تشغيله مرة أخرى بعد تحديث الحزم.

## 6) أوامر المساعدة
بعد الاتصال، افتح محادثة البوت أو مجموعة يكون فيها، واكتب:

```text
.help
```
قد تختلف الأوامر المتاحة حسب حالة المكتبات وواجهات الخدمات الخارجية.

## 7) تشغيله في الخلفية
يمكن استخدام:

```bash
pkg install tmux -y
tmux new -s bodybot
npm start
```
لفصل الجلسة مع استمرار التشغيل اضغط `Ctrl+B` ثم `D`. للعودة:

```bash
tmux attach -t bodybot
```
سيظل البوت يعمل فقط ما دام Termux يعمل والهاتف لا يوقفه في الخلفية؛ عطّل تحسين البطارية لـ Termux من إعدادات الهاتف عند الحاجة.

## إيقاف البوت
داخل نافذة التشغيل اضغط `Ctrl+C`.

## ملاحظات
- لا تشارك مجلد `session` أو ملفات بيانات الدخول؛ هذه الملفات تسمح بالوصول إلى حساب واتساب المرتبط.
- لا تحذف مجلد `session` أثناء عمل البوت. لحذف الربط، أوقف البوت أولًا ثم احذف محتويات `session`، وبعدها اربطه من جديد.
- إذا ظهر خطأ تثبيت، انسخ رسالة الخطأ النصية كاملة دون مشاركة رموز الربط أو ملفات الجلسة.
