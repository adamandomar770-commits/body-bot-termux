# body bot

نسخة مهيأة للتشغيل على Termux من المشروع المرفق، مع تغيير الاسم وإزالة بيانات جلسة واتساب المضمّنة.

**دليل التشغيل العربي:** اقرأ `README-TERMUX-AR.md` قبل البدء.

هذا مشروع غير رسمي يستخدم Baileys. قد يعرّض استخدامه حساب واتساب للتقييد، ولا تستخدمه للرسائل المزعجة أو أي نشاط مخالف.

## حقوق المشروع
تم الاحتفاظ بملفات المشروع وملاحظات الحقوق الأصلية قدر الإمكان. راجع ملفات المصدر لمعرفة التراخيص والإسناد الخاص بالمكتبات والمكونات المستخدمة.
